# 思高小助手（Sigao AI）

天主教思高圣经线上读经助手。你可以在手机或电脑上阅读旧约、新约，全文搜索经文，接着上次的进度继续读；每一章还配有 AI 辅助的经文总结、历史背景、圣人诠释与祈祷指引。

打开站长提供的网址即可使用，**无需注册、无需登录、免费**。

## 三步开始

1. **打开网站**：在浏览器输入站长提供的网址。
2. **选择经文**：在首页点选书卷与章节，或在搜索框输入书名、关键词。
3. **开始阅读**：需要辅助时，点页面底部的「经文总结」「历史背景」「圣人诠释」「祈祷指引」。

## 读经

- 旧约、新约分栏浏览，按福音书、书信等类别归类，可折叠收起。
- 每卷书有章节目录，阅读页可用「上一章 / 下一章」连续阅读。
- 经文逐节编号，方便查找与引用。
- 字号提供「小 / 默认 / 大」三档，可随时切换。
- 支持日间模式与夜间模式，适合白天读经或睡前阅读。
- 长页面提供「返回顶部」按钮。
- 字号与主题会自动记住，下次打开仍是你习惯的设置。

## 搜索

- 可搜索**书卷名**或**经文内容**。
- 搜索结果会显示经文出处（书卷、章、节），并高亮关键词。
- 经文结果较多时分页显示。
- 点击一条结果，会直接跳到该章，并定位到对应经文。

## 继续阅读与最近阅读

首页会显示两张卡片：

- **继续阅读**：回到你最近读的那一章。30 天内有效。
- **最近阅读**：最多保留 100 条阅读记录，点开即可回到相应章节。

这些记录只保存在**当前浏览器**中，不会上传到服务器，也不会在手机与电脑之间同步。

## AI 读经辅助

进入任意一章，页面底部有四个按钮：

| 按钮 | 为你提供 |
| --- | --- |
| 经文总结 | 用简明、有层次的方式总结本章内容 |
| 历史背景 | 写作年代、社会与宗教环境、人物背景与关系 |
| 圣人诠释 | 教父、圣人、圣师、教宗对相关经文的诠释与教导 |
| 祈祷指引 | 按「阅读、默想、祈祷、默观」整理的祈祷文或默想指引 |

使用说明：

- 生成过程会显示进度，完成后以排版好的文字呈现。
- 若上游返回引用资料，会列在回答末尾，可点开核对来源。
- 对回答不满意，可点「重新生成新回答」再试一次。
- 已生成过的内容会缓存，再次查看通常可以立即显示。

> AI 内容由 **Magisterium AI** 生成，采用天主教视角与思高圣经译名（如「玛利亚」「梅瑟」），开头会注明来源与限制。AI 可能出现错误，**不能取代神父、教会训导权或圣经原文**；重要问题请咨询教会牧者。

## 设备与浏览器

- 手机：iOS 10 及以上、Android 5.0 及以上，含微信内置浏览器。
- 电脑：Chrome 49+、Firefox 52+、Safari 10+、Edge 79+。
- 页面自适应 320px 至 1920px 屏幕宽度，手机横竖屏均可阅读。

## 隐私说明

- 本站**没有帐号系统**，不需要填写姓名、手机号或邮箱。
- 阅读进度、最近阅读、字号和主题保存在浏览器本地（localStorage）。
- 使用 AI 功能时，当前章节的经文会发送至 Magisterium API 以生成回答；生成结果会缓存在服务器。
- 本程式不含广告或统计追踪脚本。
- 清除浏览器数据、使用无痕模式或更换设备后，阅读记录不会保留。

## 常见问题

**需要注册或付费吗？**
不需要。打开网址即可阅读，所有功能免费。若使用人数较多，AI 功能可能暂时提示「请求过于频繁」，稍后再试即可。

**我的阅读记录为什么不见了？**
阅读记录保存在当前浏览器。使用无痕模式、清理浏览器数据、更换手机或电脑，都会看不到原来的记录；「继续阅读」也只保留最近 30 天。

**AI 按钮一直显示等待或报错？**
可能是管理员尚未配置 AI 服务、上游服务繁忙或网络不稳定。可以稍后再试；若持续失败，请向站长反馈。

**AI 的回答一定正确吗？**
不一定。AI 生成内容仅供参考，请以圣经原文与教会训导为准，并善用回答末尾的引用资料自行核对。

**为什么译名和其他版本不同？**
本站采用天主教思高圣经的译名，例如「玛利亚」「梅瑟」，与基督教和合本的「马利亚」「摩西」不同。

**可以离线阅读吗？**
不可以，需要联网打开网页。

## 给站长：自行架设

<details>
<summary>展开查看部署与管理说明</summary>

环境要求：Node.js 18+、MySQL 8.0；推荐使用 Docker。

```bash
git clone <本仓库地址>
cd sigao-ai
cp .env.example .env
# 编辑 .env：数据库、管理员帐号、MAGISTERIUM_API_KEY
docker compose up -d
```

启动后访问 `http://localhost:3000`，管理后台为 `/admin`。首次使用需在后台「圣经导入」上传 Excel 数据；导入会清空现有圣经数据，请谨慎操作。

管理后台提供：

- 圣经导入：从 Excel 批量导入经文
- AI 提示词管理：调整四种 AI 功能的提示词与系统设定
- AI 结果管理：查看、删除生成结果缓存

部署前务必修改默认管理员密码，并妥善保管 `.env`。详细说明见 [部署文档](docs/deployment.md)、[配置说明](docs/CONFIGURATION.md) 与 [快速开始](docs/QUICK_START.md)。

</details>
